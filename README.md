# Conselho do Dia — Igreja Vidas

Publica automaticamente, todos os dias por volta das 6h (horário de Fortaleza), um Story no Instagram com o versículo do devocional *Sabedoria para a Vida — 60 dias em Provérbios* (NAA). Depois do Dia 60, recomeça no Dia 1.

- `stories/` — as 60 imagens (1080×1920)
- `lista-dos-60-dias.csv` — qual versículo sai em cada dia
- `publicar.py` — o robô que publica (versão 1.0)
- `.github/workflows/publicar.yml` — o agendamento diário
- `registro.txt` — histórico do que foi publicado

Para publicar manualmente (teste): aba **Actions** → **Conselho do Dia** → **Run workflow**.
